# Mandatory Design Skill Reference

## Rule

Before performing **any** UI, UX, frontend, styling, layout, component, or design-related work in this project, you **MUST** read and follow the instructions in [`design-skill.md`](file:///c:/Users/rahul/OneDrive/Desktop/APIp_codeBase/design-skill.md).

This is a **non-negotiable, mandatory step** — no exceptions.

## When This Rule Applies

This rule applies whenever the task involves any of the following:

- Creating, modifying, or deleting UI components
- Changing CSS, styles, themes, or design tokens
- Building or editing pages, layouts, or navigation
- Working on animations, transitions, or motion
- Designing empty states, error states, or loading states
- Adding or modifying icons, colors, typography, or spacing
- Creating landing pages, dashboards, or workspaces
- Any frontend code change that affects what the user sees

## Required Actions

1. **Read** the full `design-skill.md` file at the project root using `view_file`.
2. **Follow** every principle, anti-pattern checklist, and implementation rule defined in it.
3. **Run** the Final Design Quality Checklist (Section 31) before considering any UI task complete.
4. **Apply** the Human Design Test (Section 28) to verify the result doesn't look AI-generated.

## Scope

This rule applies to the **entire project** — all pages, components, and design work across all subdirectories.
